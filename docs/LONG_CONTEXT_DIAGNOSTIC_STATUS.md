## 基建缺口

电池 adapter 在 `charge()` 后读取正确的本步 SOC，随后调用 `next_time_step()`，再用新的数组位置构造公开观测。该位置尚未由下一次 charge 写入，导致中间时刻公开 SOC 为零、回执 SOC 非零。完整时域的协议重建只证明消息忠实于公开观测，未检查观测本身是否物理正确。这是此前验收的真实遗漏，需补跨观测/回执/原生状态的语义一致性测试。

`public_action_result_from_receipt()` 当前仅对外层字段做白名单，对整个 `info` 透传。关键词扫描未发现显式 oracle/reference 答案，但发现 EV `scheduled_departure_step`，应判断是否为用户可知的出发约定，不能直接认定泄漏或安全。关键词扫描不是信息隔离证明；仍需逐路 info 字段审核及未来安排扰动下的同前缀公开消息对照。

下一步优先处理电池观测一致性、回执公开字段边界、长会话预算策略；在此之前不发布长期责任成功率。
