# V4 Flash pilot offline contract review (v2)

This is the offline pre-API stage. No online Agent calls were made after the prior rejected pilot. The 15 contracts are now hand-authored before any native witness execution and are stored in `generated/episode_pilot_v4_flash_offline_v2/task_contracts.json` and `task_contracts.md`.

Each canonical route has one concrete engineering task with a user-facing terminal/process goal, seed and public initial-state precondition, 2–4 decision steps (EV has a seed-3 26-step public connection precondition plus two evaluated decisions), route cadence and native horizon, typed units, fixed thresholds/tolerances, trajectory constraints, termination rule, and a legal but goal-failing counterexample. Validity checks such as finite values, accepted actions and positive time are recorded as execution checks only; they cannot satisfy `task_success`.

The machine-readable `task_clauses` contain route-specific operators such as `equals`, `one_of`, `range`, `min`, `max`, `min_delta_from_initial`, `min_delta_from_prefix`, `all_of` and `finite`, with public-state field paths. Examples include D0 lights off while the front door remains closed; battery SOC increase by at least 0.05 without exceeding 1.0; EV vehicle SOC/dual-port targets under public connection preconditions; IAQ CO2 threshold; water tank/served-flow predicates; FDS visibility and temperature over four replay decisions; and shared-heat allocation for both services with shortfall bound. CityLearn single-building is explicitly Episode-only and not D3 coupling.

The corrected bridge contract is an outer JSON object `{"action": scalar|list|dict}` decoded before native validation. It exposes neutral typed schemas, never witness actions. The planned evaluator runs independent witness, correctly labeled baseline, targeted legal violation, and same-seed replay, with clause-level outcomes. Multi-turn execution appends canonical assistant actions and exact environment action-result plus lossless observation deltas; checkpoints bind contract/source/model/runtime hashes and preserve rejected parsed actions.

Offline checks pass: 15/15 routes, all horizons 2–4 evaluated steps, machine clause schema valid, scalar/list/dict transport round-trip valid, and contracts serialized before native execution. Native witness/baseline/violation/replay validation is deliberately deferred until root reviews this corrected task table. No API call or core backend modification occurred in this stage.
